## Instructions 📋

### Windows 💻

1. Download the `.cur` file from this repository to your computer.
2. Open the Start Menu and search for Mouse settings.
3. Click on Additional mouse options (usually on the right side or bottom of the window).
4. Go to the Pointers tab in the new window that opens.
5. Select the cursor state you want to change (e.g., Normal Select).
6. Click Browse... and select your downloaded `.cur` file.
7. Click Apply and then OK.

### Linux 🐧

1. Download the `.cur` file.
2. Open your terminal.
3. Convert or move the cursor into your local icons directory by running:
```bash
mkdir -p ~/.icons/default/cursors
cp path/to/downloaded.cur ~/.icons/default/cursors/left_ptr
```
4. Use code with caution.
5. Restart your session or use a tweak tool (like gnome-tweaks) to reload your cursor theme.

### MacOS 🍎

1. Download the `.cur` file.
2. Download and install a cursor customization tool such as __Mousecape__ or __CursorSense__.
3. Open the tool and import the `.cur` file into a new "cape" or profile.
4. Assign the image to the desired pointer state (e.g., Arrow).
5. Apply the theme within the application.
